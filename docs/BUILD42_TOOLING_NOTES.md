# Build 42 Tooling Notes

---

## Standard Project Zomboid mapping tools

Project Zomboid custom map creation uses three primary tools maintained by The Indie Stone:

| Tool | Purpose |
|---|---|
| **TileZed** | Tile painting and zone definition; produces .tbx files |
| **WorldEd** | Cell-level world layout; manages the BMP heightmap and cell grid |
| **BuildingEd** | Individual building interior layout editor |

Downloads are available from The Indie Stone's official modding resources.
Do not commit tool installers or tool binaries to this repository.

---

## Build 42 compatibility

**No Build 42 compatibility is claimed for this mod.**

Build 42 introduced significant changes to the world generation system, tile
format, and tooling pipeline. Compatibility must be verified by:

1. Installing the B42-compatible version of TileZed and WorldEd.
2. Loading a test cell locally in B42 without errors.
3. Confirming that generated lotpack/lotheader/bin files load correctly in-game.

Until all three steps are confirmed, all content in this repository is treated
as B41-era scaffold only. Any B42 claim requires a documented local load test.

---

## Generated file policy

The following file types are generated by WorldEd/TileZed and should only be
committed after a successful local load test:

- `*.lotpack`
- `*.lotheader`
- `*.bin`
- BMP heightmaps
- Large tile exports

Do not commit these files during the scaffold or planning phase.
The `.gitignore` excludes them by default.

---

## Recommended verification order

1. Install TileZed (B42 build).
2. Open WorldEd and create a new 1x1 cell project.
3. Paint a minimal road tile in TileZed.
4. Run a local game load test.
5. Only then begin committing generated output.
